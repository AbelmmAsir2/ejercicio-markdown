# Guía del proyecto

Esta guía explica la estructura básica del repositorio.

## Archivos

- `README.md`: archivo principal.
- `guia.md`: documento complementario.
- `images/captura.png`: imagen almacenada en el repositorio.

## Pasos

1. Abrir el repositorio.
2. Revisar el archivo README.md.
3. Comprobar que se muestran las imágenes.
